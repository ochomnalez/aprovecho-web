# Aprovecho · sitio

Página pública de Aprovecho: **https://ochomnalez.github.io/aprovecho-web/**

Una sola página, sin build ni dependencias: HTML, CSS y JS a mano. Las capturas
de `img/app/` salen de la app real, que vive en
[aprovecho-app](https://github.com/ochomnalez/aprovecho-app).

Para verla en la compu:

```bash
python -m http.server 8792
```

> *Nada se pierde, todo vale.*
